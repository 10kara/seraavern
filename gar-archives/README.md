# GAR Archives — личное дело капрала «Рифа»

Интерактивное **бумажное личное дело** капрала CT-6977 «Тенкара» из 91-го
разведывательного корпуса Гранд Армии Республики: тёмный канцелярский стол,
подшитые листы с машинописью, фотографии под скотч, красные печати и
рукописные пометки. Досье, история службы, схема связей, фотогалерея и
полноценная админ-панель.

## Персонаж
- **Позывной:** Тенкара (CT-6977)
- **Должность:** заместитель командира отряда ОСН «Мантикора»
- **Звание:** капрал ГАР
- **Подразделение:** 91-й разведывательный корпус (ранее — БСО на Анаксисе, 69-й полк)
- **Квалификация:** ARC-боец (с службы в 69-м полку)
- **Главы:** Камино → Анаксис (БСО) → 69-й полк (сержант, ARC) → Акулорум (91-й разведкорпус)

## Дизайн v2 — «бумажное дело»
- Тёмный деревянный стол с волокнами, на нём — листы дела
- Машинопись (PT Mono), печати и заголовки (Oswald), рукописные цитаты (Caveat)
- Красная линия полей и синяя разлиновка на листах, кусочки скотча на панелях
- Круглые и прямоугольные печати: «ДОПУСК УТВЕРЖДЁН // 91 РК», «ОЗНАКОМЛЕНО»
- Засекреченная «ГРАФА 14-Б» с чёрными купюрами, штрих-код, телеграфная лента
- Схема связей на миллиметровке: синий и красный карандаш
- Фотографии-отпечатки с сепией и зерном («Архивный снимок»)
- Тема по клавише `T`: «Республика» (тёплая бумага) ⇄ «Империя» (серые листы цензуры)

## Запуск
```bash
npm install
npm run dev
```

## .env
Скопируйте `.env.example` в `.env` и укажите:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
- при необходимости `VITE_ADMIN_EMAIL`

Авторизация — через Supabase Auth. Без подключённого Supabase сайт работает
в демо-режиме на локальных данных личного дела.

## Supabase
1. Выполните `SUPABASE_POLICIES.sql` целиком в SQL Editor (RLS, политики,
   таблицы `gallery` и `character_links`, координаты сети).
2. Выполните `SUPABASE_STORAGE.sql` — создаёт публичный bucket `archive`.
3. (Опционально) `HOLO_EFFECT_SQL.sql` — колонка `holo_effect` («Архивный снимок»).

Отдельные миграции `NETWORK_SCHEMA.sql` / `HOLO_EFFECT_SQL.sql` безопасно
запускать повторно.

## Таблицы
`character`, `chapters`, `relationships` (+ `pos_x`, `pos_y`, `group_tag`),
`character_links` (`from_id < to_id`), `gallery` — как в описании SQL-скриптов.

### Горячие клавиши
- `T` — смена темы (Республика ⇄ Империя);
- `Ctrl+S` — сохранить форму в админке; `Esc` — отменить редактирование;
- `↑↑↓↓←→←→` — «дело изъято» (Орден 66).

## Деплой
GitHub Actions публикует сайт на GitHub Pages (`/gar-archives/`).
Секреты: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
(или `VITE_SUPABASE_PUBLISHABLE_KEY`), `VITE_SUPABASE_STORAGE_BUCKET`.
